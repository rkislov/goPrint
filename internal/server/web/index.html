Подключение компьютера

Автоматическая настройка системной очереди через IPP.

Установка принтеров

Скачайте сценарий для своей ОС, проверьте его и запустите с правами установки принтера. Документы проходят очередь GoPrint, watermark и PPD на сервере. Пароли в сценарии не включаются. Подключение использует отдельный вход; автоматический Windows SSO пока не реализован.

Linux: нужен работающий CUPS с поддержкой IPP Everywhere. Windows: нужен Add-Printer с параметром IppURL. Требуется доверенный сертификат сервера; совместимость входа через системный драйвер проверьте до массового развёртывания. Настройки бумаги и дуплекса остаются значениями PPD по умолчанию.

Доступность фильтров на этом сервере

Официальные пакеты Катюша · Linux amd64

Скачиваются вместе с каталогом производителя. Для ARM64 в этом пакете фильтров нет. Установка и зависимости проверяются администратором; сценарии производителя автоматически не запускаются.

УниверсальныйM130/P130M247M348

Фильтры с системными зависимостями устанавливаются пакетами для конкретной ОС. Для выбранного PPD цепочка выполняется автоматически через системный cupsfilter.

Передача событий в SIEM

Syslog · RFC 5424 · TCP / TLS

Для TLS проверяется сертификат через системное хранилище доверия.

Что передаётся

Идентификатор события и задания, пользователь, принтер, время, статус, формат и размер. Содержимое и название документа не передаются.

События хранятся локально. После восстановления соединения экспорт продолжается с сохранённой позиции; возможны дубликаты. Для их удаления используйте пару instance_id + event_id. TCP-передача не подтверждает индексацию события в SIEM.

Политика маркировки

Переменные: {{user}} — пользователь, {{job}} — задание, {{date}} — дата UTC.

При включённой политике разрешены только PDF. Ошибка маркировки блокирует отправку документа. Политика применяется к заданиям в момент отправки.

Отправка с МФУ

Настройте на устройстве назначение WebDAV. Пароль устройства показывается только сейчас.

Для доступа МФУ по сети сервер должен быть запущен с HTTPS и сетевым адресом. Текущий loopback доступен только на этом компьютере.
