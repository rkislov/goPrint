Подключение компьютера

Автоматическая настройка системной очереди через IPP.

Установка принтеров

Скачайте сценарий для своей ОС, проверьте его и запустите с правами установки принтера. Документы проходят очередь GoPrint, watermark и PPD на сервере. Пароли в сценарии не включаются. Подключение использует отдельный вход; автоматический Windows SSO пока не реализован.

Linux: нужен работающий CUPS с поддержкой IPP Everywhere. Windows: нужен Add-Printer с параметром IppURL. Требуется доверенный сертификат сервера; совместимость входа через системный драйвер проверьте до массового развёртывания. Личные параметры печати задаются в разделе «Мои принтеры».

Передача событий в SIEM

Syslog · RFC 5424 · TCP / TLS

Для TLS проверяется сертификат через системное хранилище доверия.

Что передаётся

Идентификатор события и задания, пользователь, принтер, время, статус, формат и размер. Содержимое и название документа не передаются.

События хранятся локально. После восстановления соединения экспорт продолжается с сохранённой позиции; возможны дубликаты. Для их удаления используйте пару instance_id + event_id. TCP-передача не подтверждает индексацию события в SIEM.

Состояние принтеров и расходников

Показания устройства, счётчики и предупреждения

Мониторинг включается отдельно для каждого принтера. Для счётчиков используйте SNMP Printer MIB. IPP возвращает состояние и доступные уровни расходников. «Нет данных» не означает нулевой остаток. При ошибке показаны последние успешные показания с датой.

Уведомления администраторам

Используется SMTP из раздела «Почта» и список разрешённых доменов получателей. Изменение уровня предупреждения создаёт новое уведомление. «Принято в работу» отключает напоминания до изменения уровня. При неизвестном результате SMTP письмо немедленно не повторяется.

Приём сканов

Назначения WebDAV / FTP / FTPS и получатели документов.

Назначения для устройств

У каждого назначения свои логин и пароль, привязанные к получателю. Имя файла не меняет владельца. Одна общая учётная запись МФУ не определяет пользователя у панели: создайте личные назначения в адресной книге или интегрируйте вход на МФУ.

FTP / FTPS на сервере

FTPS — explicit TLS (AUTH TLS), TLS 1.2+, оба канала защищены. Сертификат берётся из HTTPS-настроек запуска GoPrint. FTP без TLS требует явно заданных подсетей и разрешения в назначении. Активный режим отключён; на МФУ включите PASV/EPSV. Изменение настроек разрывает текущие FTP-сеансы; незавершённые файлы удаляются.

Новое назначение

Доменный получатель проверяется через LDAP при загрузке. При смене получателя пароль автоматически меняется; старые сеансы больше не смогут публиковать файлы. Для нового назначения без eSCL создаётся устройство только для приёма.

Параметры для МФУ

Пароль показывается один раз. Сохраните его в адресной книге МФУ и защищённом хранилище.

Почтовый сервер
SMTP для автоматической доставки документов по личным правилам пользователей.
Сертификат SMTP проверяется. Пароль хранится зашифрованным; ключ smtp.key резервируется вместе с каталогом данных.
Печать по email
Доверенный MTA подтверждает отправителя, GoPrint связывает адрес с атрибутом mail в домене. Нельзя передавать неподтверждённое поле From. Служебный LDAP bind задаётся в domain.json.
До 10 вложений PDF/JPEG/PNG, суммарно 20 МиБ. Форматы ограничиваются принтером. Используйте goprint-mail-submit на шлюзе по инструкции.


Домен и Windows SSO
Kerberos/SPNEGO для входа с текущей доменной учётной записью Windows.
Состояние Kerberos
Realm, HTTP/SPN, LDAPS и путь keytab задаются в domain.json. Серверу нужны HTTPS и служебная учётная запись LDAP для проверки групп. Порядок создания keytab приведён в инструкции администратора.
До 1 МиБ. Проверяются realm, SPN и наличие AES-ключа. Файл сохраняется с правами 0600; замена применяется без перезапуска.


Доступ к принтеру
Без правил устройство доступно только администраторам. Настройки действуют и для веб-печати, и для IPP.


Антивирусная проверка
Перед печатью, получением и отправкой сканов.
ClamAV: unix:///path/socket или tcp://host:3310. ICAP: icap://host:1344/service или icaps://host:1344/service. Если проверка включена, ошибка связи блокирует документ. Для ICAP чистый результат должен возвращать 204.
