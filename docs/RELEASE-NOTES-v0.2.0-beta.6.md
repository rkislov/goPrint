# GoPrint v0.2.0-beta.6

4 ноября 2026 г. · Apache License 2.0 · Кислов Роман Сергеевич

Обновление посвящено проверке RPM и штатной службы systemd на ALT Linux 10 и 11. Функции печати, сканирования, домена/SSO, Sindoh и диагностики сохранены.

## Служба и пакеты ALT

Добавлен воспроизводимый интеграционный тест для одноразовых виртуальных машин с systemd как PID 1. Проверяются установка и первый запуск, непривилегированный UID, реальные ограничения файловой системы и приватный /tmp, сохранение очереди при остановке и перезагрузке, печать через PPD, обновление с beta.5 без самовольного перезапуска активной службы, Restart=on-failure и удаление/повторная установка с сохранением данных и конфигурации.

Штатный unit используется без тестовых переопределений и ослабления защиты. Результаты, образы ОС, границы проверки и команды воспроизведения: [ALT-LINUX-VALIDATION.md](https://github.com/rkislov/goPrint/blob/v0.2.0-beta.6/docs/ALT-LINUX-VALIDATION.md).

Сборка архива теперь берёт упаковку ALT из зафиксированных файлов Git, исключая временные файлы Python. SHA256SUMS включает только RPM текущего выпуска. Обновлены инструкции и PDF. Презентация сохранена без версии и отметки бета внутри.

## Установка и обновление

Выбирайте RPM своей ветки p10/p11 и архитектуры x86_64/aarch64. Проверьте SHA256SUMS, установите пакет через apt-get install с путём к RPM. Для новой установки выполните goprint-setup от root, сохраните токен из /etc/goprint/environment и включите службу: systemctl enable --now goprint. По умолчанию интерфейс доступен только на 127.0.0.1:8631.

Перед обновлением остановите приём заданий и сохраните согласованную резервную копию базы, spool, сканов, конфигурации и ключей. Обновлённый пакет сохраняет изменённый environment; запуск новой версии выполняйте явно через systemctl restart goprint. Отдельная SQL-миграция не требуется. После удаления изменённая конфигурация может сохраняться в .rpmsave: перед повторной настройкой восстановите её, чтобы сохранить прежний токен.

RPM не подписаны GPG. Проверка на виртуальных машинах не подтверждает физический выход бумаги, сквозной вход в реальный домен или доставку почты в инфраструктуре заказчика.
