# GoPrint v0.2.0-beta.7

16 ноября 2026 г. · Apache-2.0 · Кислов Роман Сергеевич

- Администратор может задать название, логотип и основной цвет. Обязательная подпись «Работает на GoPrint» видна на входе, в интерфейсе и на печатной QR-наклейке.
- Принтер по умолчанию назначается пользователю или доменной группе. Личный выбор доступного принтера имеет приоритет. В меню «Печать» показаны действующее назначение и его источник.
- Руководства администратора и пользователя дополнены скриншотами. Презентация продукта приложена в PDF и PowerPoint.
- Выпуск включает Linux-архивы, RPM для ALT 10/11, DEB для Ubuntu 24.04 LTS и Astra Linux SE 1.8, RPM для CentOS Stream 9 и РЕД ОС 8. Целевые архитектуры и команды приведены в инструкции установки Linux.

Сборки используют Go 1.26.11 с исправлением [GO-2026-6859](https://pkg.go.dev/vuln/GO-2026-6859).

Перед обновлением сохраните резервную копию конфигурации и данных, затем проверьте скачанный пакет по SHA256SUMS. После установки перезапустите службу. Брендирование и назначения хранятся в основной базе настроек.
