# PPD Sindoh

В каталог добавлен отдельный источник официальных Linux-пакетов [Sindoh](https://www.sindoh.com/en/business/printing-solution/download). Индексируются 15 англоязычных PPD: PostScript PS(P) и OpenOffice для D320/D330/CM2043, D710, D720/CM4091, D740/CM4097, N500, N800/MF4093, N910/MF7121; отдельный профиль N610_410 Series PS. Это названия из самих PPD, а не обещание совместимости всех моделей, перечисленных на сайте загрузок. Некоторые официальные ссылки разных моделей ведут на один и тот же архив; дубликаты исключены.

В «Настройки → Каталог PPD» нажмите «Загрузить / обновить», выберите производителя **Sindoh** и нужный профиль. При стандартном запуске с предзагрузкой источник также скачивается автоматически, если Sindoh ещё отсутствует. Параметр -preload-ppds=false отключает автоматическую загрузку всех источников; обновление вручную остаётся доступным. Состояние загрузки и ошибки показаны отдельно от OpenPrinting и Катюша. Обновление OpenPrinting и перезапуск сохраняют профили Sindoh.

Загружаются восемь проверенных официальных ZIP-пакетов. Список URL и SHA-256 находится в [sindoh-sources.json](../internal/drivers/sindoh-sources.json). Извлекаются английские PPD для CUPS 1.2 и PPD из вложенного tar.gz N410/N610. Устаревшие дубликаты CUPS 1.1 и отдельные локализации не индексируются. PPD и исходные ZIP сохраняются в приватном каталоге ppds; установщики, скрипты и бинарники не запускаются. При изменении архива загрузка блокируется до проверки новой контрольной суммы.

Для изолированной установки скачайте ZIP по ссылке из манифеста на доверенном компьютере, перенесите на сервер и выполните от владельца каталога данных при остановленной службе:

```sh
goprint-ppds -dir /var/lib/goprint/ppds -sindoh -archive /secure/Sindoh_Linux_v20002.0001.zip
```

Повторите для нужных пакетов. Импорт принимает только архивы из проверенного манифеста и объединяет профили без удаления других источников. Самих пакетов производителя в GitHub и архивах GoPrint нет — они загружаются с сайта Sindoh. PPD не перелицензируются под Apache 2.0; исходные уведомления и лицензии сохранены в файлах и исходных архивах.

Для PS(P)/OpenOffice требуются системные cupsfilter и преобразование PDF → PostScript; устройство должно принимать PostScript. Сначала проверьте обычную тестовую страницу, затем бумагу, дуплекс и цвет для своей модели. Выбранный PPD участвует в общей цепочке печати GoPrint. Для N410/N610 PPD явно требует фирменный /usr/lib/cups/filter/Sindoh/PS/Filters/SindohPS: администратор устанавливает совместимый фильтр и зависимости отдельно из пакета производителя. GoPrint не заменяет его общим PostScript-фильтром. Совместимость бинарника/фильтра с ARM64 не заявлена; отсутствие требуемого фильтра блокирует печать.

Проверено 04.11.2026: импорт всех восьми официальных пакетов, 15 PPD, сохранение в индексе и преобразование синтетического PDF через PPD D320/D330 в PostScript. Физический принтер и фирменный фильтр N410/N610 в этом испытании не использовались. Поддержка включена в выпуск v0.2.0-beta.5.
