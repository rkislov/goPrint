# GoPrint v0.2.0-beta.5

4 ноября 2026 г. · Apache License 2.0 · Кислов Роман Сергеевич

## Новое

- RPM для ALT Linux 10 (p10) и 11 (p11), x86_64 и aarch64. Отдельный пользователь службы, защищённая конфигурация, goprint-setup со случайным токеном, systemd unit и зависимости CUPS/Ghostscript. Сервис запускается администратором после настройки.
- В ALT раздел фильтров показывает команды apt-get install вместо загрузки пакетов Debian. Добавлен поиск фильтров в /usr/lib64/cups/filter.
- Каталог 15 официальных PPD Sindoh с проверкой SHA-256 архивов. Источники и ограничения описаны в SINDOH.md. Фирменные исполняемые драйверы отдельно, N410/N610 требует SindohPS.
- Обновлены инструкции администратора и пользователя, PDF со скриншотами и отдельное руководство установки ALT. Презентация продукта сохранена без номера версии и отметки бета внутри.

Сохраняются диагностика LDAP/SSO, SMB, SMTP и устройств, мобильная очередь, QR, Follow Me, сканирование, WebDAV/FTP/FTPS, антивирус, watermark, SIEM, мониторинг и PostgreSQL.

## Поставка и обновление

Два Linux-архива и четыре RPM содержат статические бинарники с метаданными версии/коммита. Go для запуска не требуется. PPD производителей и дополнительные драйверы загружаются отдельно и сохраняют собственные лицензии. RPM не подписаны GPG; SHA256SUMS содержит контрольные суммы архивов, RPM и документов. Выбирайте пакет своей ветки и архитектуры.

Перед обновлением остановите службу и сохраните согласованный комплект БД, spool, сканов, конфигурации и ключей. Для RPM используйте apt-get install с путём к пакету; изменённая конфигурация сохраняется, запуск после обновления выполняется явно. Для архивной установки замените шесть бинарников с прежними правами. Отдельная SQL-миграция не требуется. Подробности перехода с ручного unit и каталогов: ALT-LINUX.md. Проверьте версию, вход, фильтры и разрешённую тестовую печать.

## Границы проверки

Контейнерные проверки RPM охватывают установку, непривилегированный API, PDF → PPD → PostScript, переустановку и сохранение конфигурации/данных при удалении. Unit проверяется systemd-analyze verify, без загрузки systemd как PID 1. Сквозные доменный вход, физические устройства, сетевые службы и загрузка ALT на целевой машине требуют отдельного пилота.
